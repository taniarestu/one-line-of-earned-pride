A make.fun entry for **One Line of Earned Pride** (`u-mang-one-line-of-earned-pride-a0138557`).

`main.py` (Python 3.13, stdlib only, no network, deterministic) writes one line
of text, 1 to 240 characters, to `/output/entry.txt`: a quiet, earned moment
of pride for someone in a scene.

## The entry

> After a year of practising in the bathroom mirror, ten-year-old Sam read the school assembly announcement all the way through without stumbling once, then sat down like nothing had happened.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (190 characters, one line).
